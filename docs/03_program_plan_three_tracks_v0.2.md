## 0. 本次任务的三条线

1. **A 教材线（第一优先）**：在 v0.2 原创骨架（12 章）基础上，按章节规划用网络资源充实内容，成全书评审稿。
2. **C 线上实践线（第二步）**：即 v1.0 方案全部内容（阶段0–3、G0–G7、WP0–7）。启动输入＝A 线成果（至少试点章定稿，任务书以定稿章为据）。
3. **B 教学视频线（最后）**：按 103 项目已验证流程与经验，依全书定稿批量生产章节微课。生产线成熟，前置条件只有"教材定稿"。

**三线是同一门课的三个交付层**：教材＝内容之源，线上实践＝交互验证层，视频＝知识传递层。顺序上先固内容，再建交互，最后做传递。

## 1. 顺序与同步机制

```text
A 教材线（先行）
  ├─ 第一批：试点章 4–5（公共生活空间）充实定稿
  └─ 逐批滚动 → 全书评审稿
        │ (全书评审稿为启动门)
        ▼
C 线上实践线（v1.0 方案）
  阶段0 技术审计 → 阶段1 MVP（任务书/情境取材定稿试点章）→ 阶段2 课堂试点 → 阶段3 推广
        │ (定稿教材 + 试点验证完成)
        ▼
B 教学视频线（收尾批量）
  全书微课清单 → 按章批量生产（脚本→关键帧→i2v→剪辑QA，复用103生产线）
```

- **同步单元＝章**：教材一章定稿即为该章后续一切（任务书、实验、视频脚本）的合格输入；A 线内部逐批滚动，C/B 不抢跑。
- **R7 解耦原则贯穿**：教材章节ID、视频资产ID、实验任务ID三者分离，运行时挂接；任何一层替换不影响其他层记录。
- **可选项（待课程负责人定夺）**：阶段0的 OpenPlan3D 技术审计是纯技术调研、不依赖教材内容，若希望缩短总周期，可在 A 线后期并行启动；默认不并行，严格按序。

## 2. A 线：教材充实工作流（v0.2 → 全书评审稿）

现状：v0.2 为原创骨架稿（12 章约 5.3 万字），案例与数值均标注"教学假设/须核验"，配图未做。充实循环：

1. **逐章待核清单**：提取三类缺口——案例事实（年份/户数/机制等）、数值来源（人体尺度/声光材料数据的权威出处）、图片需求（清单+版权状态）。
2. **网络资源检索**：按清单查权威来源（标准原文、机构官网、学术文献、权威出版物转述），记录来源与可信度。
3. **改写回填**：以核实事实充实正文，保持原创表述；标注升级为四类——**已核实（注来源）／教学常用值／教学假设／须核验**。
4. **章节评审**：每章充实后出该章评审稿，教师批注。

**红线**：不复制第三方教材文字（只做事实核验与原创改写）；网络图片仅用于研究核验，正式配图须获授权或自绘/CC0；U90 沈家等教学虚构保持虚构并标注。

**批次**：试点章 4–5 第一批；随后每批 2–3 章滚动（调研子任务并发 ≤4，沿用既有限速约定）。产出 v0.3（首批）→ 逐版累积 → 全书评审稿。

## 3. C 线：线上实践（v1.0 原样，启动条件明确）

- 阶段0–3、G0–G7、WP0–WP7 全部按 v1.0 执行。
- **启动门**：A 线全书评审稿完成（或课程负责人明确放宽为"试点章定稿即可启动阶段0/1"）。
- WP0 教学样板的任务书输入＝定稿试点章（第4–5章）。

## 4. B 线：教学视频（最后批量，复用 103 资产）

**直接复用（均已验证）**：完整生产链（脚本/镜头设计→关键帧→图生视频→剪辑/QA）；ComfyUI 工作流系统（按需自建工作流是一等前置阶段）；TTS 配音（IndexTTS2，人耳验收通过）；两类可生产模板（章节卡片式、动画式），后续可扩展数学式、真人式。

**本课程适配**：
- 输入＝定稿教材 → 全书微课清单（每章 1–3 条、每条 3–6 分钟）；
- 与 R7 一致：视频资产与实验任务 ID 解耦，运行时挂接；
- **准确性 QA**：口播内容与定稿教材逐条一致（比风格 QA 更严格），逐条记录核验；
- AI 氛围图若用于片头/示意，须标注"概念图"，不冒充教材图示。

**后置的合理性**：生产线成熟＝边际成本主要在脚本与 QA，而两者都以定稿教材为输入；教材未定先做视频只会返工。后置不损失任何并行收益。

## 7. 风险登记

| 风险 | 应对 |
|---|---|
| 教材未定稿即铺开后续制作 → 大返工 | 严格按序；章为最小同步单元；启动门明确 |
| 三线串行拉长总周期 | A 线批次滚动提效；可选项：阶段0纯技术审计提前并行（须批准） |
| 网络资源充实引入版权/事实错误 | 只做核验+原创改写；四类标注；来源档案随章归档 |
| 视频批量生产的准确性 | 口播与定稿教材逐条核验绑定 |
| 三线总量被低估 | 试点章竖切先验证产能与节奏，再排全书 |
