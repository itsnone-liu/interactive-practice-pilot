# 三线总体计划：教材 · 教学视频 · 线上实践（补充方案 v0.1）

> **定位**：对《要求与实施方案 v1.0》的补充修订。v1.0 定义了"线上实践试验"；本文把另外两条任务线——教材充实成稿、按 103 项目流程经验生产教学视频——纳入同一总体计划。
> **状态**：讨论稿 · 2026-10-19 · 等待课程负责人审阅
> **原则不变**：v1.0 的 R1–R8、阶段0–3、门禁 G0–G7 全部有效，本文不改动它们，只补总体结构。

---

## 0. 本次任务的三条线（用户 2026-10-19 确认）

1. **试验线上实践**——即 v1.0 方案全部内容（本仓库主线）。
2. **完成教材编写**——在 v0.2 原创骨架（12 章）基础上，**按章节规划用网络资源充实内容**，成评审稿。
3. **完成教学视频**——按 103 项目已验证的流程与经验，为本课程批量生产章节微课。

**三线不是三个项目，是同一门课的三个交付层**：教材是内容之源（单一事实源），视频是知识传递层，线上实践是交互验证层。

## 1. 三线关系与同步机制

```text
A 教材线（内容之源） ──章定稿──▶ B 视频线（微课生产，复用103生产线）
        │
        └────章定稿──────────▶ C 线上实践线（任务书/情境/检查规则取材于定稿章）
                                     │
                课堂试点（阶段2）◀── B+C 汇合（试点章 4–5）
```

- **同步单元＝章**。一章教材充实定稿，才触发该章的视频生产与线上实验开发；避免"内容未定稿就铺开制作"的返工浪费（三线并行第一风险）。
- **试点章优先**：第4–5章（公共生活空间，对应试点实验）在 A 线最先充实，其视频与 MVP 汇合支撑阶段2课堂试点。
- **R7 解耦原则贯穿**：教材章节ID、视频资产ID、实验任务ID三者分离，运行时挂接；任何一层替换不影响其他层记录。

## 2. A 线：教材充实工作流（v0.2 → 评审稿）

现状：v0.2 为原创骨架稿（约5.3万字），案例与数值均标注"教学假设/须核验"，图像未配。充实循环：

1. **逐章待核清单**：从各章提取三类缺口——案例事实（如马赛公寓/菊儿胡同的年份、户数、机制）、数值来源（人体尺度/声光材料数据的权威出处）、图片需求（配图清单+版权状态）。
2. **网络资源检索**：按清单检索权威来源（标准原文、机构官网、学术文献、权威出版物转述），每条记录来源与可信度。
3. **改写回填**：以核实后的事实充实正文，保持原创表述；标注体系升级为四类——**已核实（注来源）／教学常用值／教学假设／须核验**。
4. **章节评审**：每章充实后出该章评审稿，教师批注。

**红线**：不复制第三方教材文字（只做事实核验与原创改写）；网络图片仅用于研究核验，正式配图须获授权或改为自绘/CC0/自制图示；U90 沈家等教学虚构保持虚构并标注。

节奏：每批 2–3 章并行充实（调研子任务并发 ≤4，沿用既有限速约定），试点章（4–5）第一批。

## 3. B 线：教学视频生产线（复用 103 流程与经验）

**直接复用的 103 资产**（均为已验证经验）：

- 完整生产链：脚本/镜头设计 → 关键帧 → 图生视频 → 剪辑/QA；
- ComfyUI 工作流系统：按需自建工作流是制作流程的一等前置阶段，新需求先建工作流再制作，不硬套现有工作流；
- TTS 配音（IndexTTS2，人耳验收通过，代际音色一致）；
- 两类已验证课件模板：章节视频卡片式、动画式（Times Square 验收认定的可生产模板）；后续可扩展数学式、真人式。

**本课程适配**：

- 按教材章节规划微课清单：每章 1–3 条、每条 3–6 分钟，优先试点章；
- 与 v1.0 §R7 一致：微课可先批量制作，运行时挂接实验任务；视频内不硬编码交互逻辑；
- **新增 QA 维度——准确性**：口播内容与定稿教材的一致性核查（比 103 风格类 QA 更严格），逐条记录核验；
- AI 氛围图若用于片头/示意，须标注"概念图"，不得冒充教材图示（与 R5 精神一致）。

## 4. C 线：线上实践（不变）

阶段0–3、G0–G7、WP0–WP7 全部按 v1.0 执行。唯一修订：**WP0 教学样板的任务书输入，以 A 线定稿的试点章为准**（而非骨架稿），时间上 A 线试点章充实排在阶段0 内并行完成。

## 7. 新增风险登记

| 风险 | 应对 |
|---|---|
| 教材未定稿即铺开视频/实验 → 大返工 | 章为最小同步单元；里程碑门禁 |
| 网络资源充实引入版权/事实错误 | 只做核验+原创改写；四类标注；来源档案随章归档 |

| 三线并行总量被低估 | 试点章竖切先行验证产能，再排全书 |
