# interactive-practice-pilot · 本科交互式线上实践课程试点方案

> **状态**：讨论稿 v0.1 · 2026-10-19 · 等待课程负责人审阅
> **试点课程**：《室内空间设计》（住宅方向，环境设计专业本科）
> **试点实验**：90㎡三居室住宅的公共生活空间设计

## 这是什么

借《室内空间设计》验证一个教学模式：**线上交互实践能否真正促进专业设计认知**——学生能否识别真实空间问题、在约束下做出并解释设计决策、并把原理迁移到新情境。本项目**不是**开发住宅设计软件，也不是把讲义视频搬上网页。

学习闭环：知识理解 → 真实问题 → 自主设计决策 → 可视化结果 → 情境验证 → 解释与反馈 → 修订方案 → 学习迁移。

## 已定的三项核心决策

1. 《室内空间设计》以住宅为主要对象，教授可迁移的室内设计原理；商业空间另设课程。
2. 废弃"方框拖动＋简单碰撞分数"作为本科实践成品；采用专业二维符号、尺寸准确的家具、真实三维场景与有意义的设计情境。
3. 三维漫游与效果图进入学习闭环，而非最后的装饰性展示；效果图必须忠实于学生实际设计的空间几何。

## 技术路线（初判，待阶段0验证）

- **OpenPlan3D**（首选审计对象，SvelteKit＋Three.js 开源编辑器）＋ **Three.js** ＋ **自建教学层**（任务／情境／证据／A-B 比较／评价——约占七成工作量）。
- 三级可视化：L1 实时三维 → L2 统一相机截图（A/B 同条件比较）→ L3 Blender 后台渲染（增强项，不阻塞 MVP）。
- 资产策略：10–15 件精选家具＋许可台账＋逐件尺寸校验。

## 阶段路线与停止条件

阶段0 教学样板＋开源技术审计（`TECH_SPIKE_REPORT.md`）→ 阶段1 完整教学竖切 MVP → 阶段2 课堂小规模试点（8–15 人）→ 阶段3 优化推广。

验收门禁 G0–G7；**G6（教学实效）失败即暂停扩张**——验证"网页实践未明显促进认知"也是有效结论。
